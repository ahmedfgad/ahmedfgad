I'm a senior AI engineer and researcher in Ontario, Canada. I've built AI for cybersecurity at Trend Micro and machine learning for cancer research at Medicia Research. I created PyGAD, an open-source genetic algorithm library, and founded Vilvik. I've also written six books and nearly 100 tutorials on machine learning, computer vision and Python, and I build mobile apps.

## What I'm Building

<a href="https://vilvik.com">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/vilvik-dark.svg">
    <img src="assets/vilvik-light.svg" width="100%" alt="Vilvik. Evolutionary optimization on the cloud, for your decisions, models, and games. No setup.">

**[Vilvik](https://vilvik.com)** is my company, an early-stage Canadian startup. Its online application runs evolutionary optimization in the cloud, so you can optimize a decision, tune a model, or evolve a game agent from the browser, the REST API, or Python, without setting anything up.

```bash
pip install vilvik
```

[Website](https://vilvik.com) · [Python SDK](https://github.com/VilvikInc/vilvik-python) · [GitHub](https://github.com/VilvikInc) · [LinkedIn](https://www.linkedin.com/company/vilvik) · [X](https://x.com/vilvikinc)

**[PyGAD](https://github.com/ahmedfgad/GeneticAlgorithmPython)** is the open-source genetic algorithm library behind it all. It handles single and multi-objective problems and can train Keras and PyTorch models.
